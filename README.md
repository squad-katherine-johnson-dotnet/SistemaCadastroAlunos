# 📚 Sistema de Cadastro de Alunos

Projeto desenvolvido em squad como parte do desafio de **Fundamentos de Programação com C#**.

## 🎯 Objetivo

Desenvolver um sistema em C# que permita **cadastrar e consultar informações de alunos**, utilizando os conceitos de programação estudados até o momento.

O desafio também tem como objetivo praticar a **divisão de tarefas, integração do código, depuração e boas práticas de programação** em equipe.

## 📌 Funcionalidades

O sistema permite:

- Cadastrar até 10 alunos;
- Armazenar nome, idade, nota 1 e nota 2;
- Listar os alunos cadastrados;
- Buscar um aluno;
- Exibir os alunos aprovados;
- Exibir a média da turma;
- Encerrar o sistema.
